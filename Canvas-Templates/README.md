# Canvas Templates – Visual template pack

A collection of Excalidraw templates for productivity, learning, creativity and storytelling. Ideal for use with **Canvas Note Tools → Insert template** (the older *Canvas Template Loader* widget was absorbed by it — see the audit of round 14).

## Templates included (16)

**Productivity**
- OKR
- GTD
- GTD – Weekly Review
- Project Board (Painel de Projetos)

**Learning**
- Cornell Notes
- Feynman Technique
- Personal User Manual

**Creativity & marketing**
- AIDA Funnel
- SCAMPER
- Design Thinking

**Narrative (writing & comics)**
- Storyboard
- Character Arc
- Plot Timeline

**Writing project (from the *super-template*)**
- Storyboard (HQ) / *Storyboard (HQ)* — one page per line, four panels per block (action · balloon · time)
- Relationship map (*Mapa de relações*) — one node per character, typed arrows
- Arc & plotline map (*Mapa de arcos & plotlines*) — acts × plotlines, markers on the beats

**Note**: the text is in Portuguese (the pack's origin) and ready to use as-is — double-click any field in the canvas to edit it.

**Update (17/10/2026, later)**: **16 templates** — the three canvases of the writing *super-template* joined the pack (**Storyboard (HQ)**, **Relationship map**, **Arc & plotline map**); they ship with a worked example inside, so the `+` of the writing template and the 🧩 *Insert template* both land on something readable. Same rules as the pack: text ≥ 12px, WCAG AA contrast measured against the real background, origin ≥ 0.

**Update (17/10/2026)**: accessibility/typography pass — WCAG AA contrast in all 13 templates, the Storyboard's cell dividers are real lines, text-overflow fixes (GTD, Manual, Design Thinking, OKR), unified background/grid/zoom, negative origins normalized; **text floor raised to 12px** (143 labels; the 5 Cornell step headers and the "RESUMO/SÍNTESE" pair stay at 11px because 12px would touch the next column, and the Storyboard's index strip stays at 9px — at 12px it is 1533px wide inside a 1260px band), corner radii collapsed to one value per template, `⬜` → `☐`, and 6 Storyboard cell labels re-centered; previews and the exported SVGs were regenerated from the current state (`fix-canvas-templates.py`, `render-canvas.py`, `test-canvas-templates.py`).

**Update (29/09/2026)**: all templates refreshed (Portuguese text polish, new fields) and a new **Project Board** template added. Source: the "Modelos Trilium" collection review (Trilium VPS `wBlaqjho7HNt`).

## Installation

**Option 1 — plugin manager** (recommended): install `canvas-templates-for-production` from the registry (Trilium-plugin-manager).

**Option 2 — manual**: import `Canvas-templates.zip` into Trilium. The notes will appear with the `#canvasTemplate` label automatically.
